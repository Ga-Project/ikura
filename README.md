# イクラ？

身近な商品やサービスの「全国平均のお値段」を当てる、1日1問の無料ゲームです。

公的統計をもとにしたその日のお題に対して価格を推測すると、「上げて／下げて」の手ごたえが返ります。6回以内に平均価格へ ±10% で近づけられれば的中。結果は絵文字グリッドで、正解の価格を伏せたまま共有できます。

**遊ぶ → https://ga-project.github.io/ikura/**

## 特徴

- **1日1問** — 出題は毎日0時に切り替わります。世界中で同じお題です。
- **ヒントで寄せる** — 「上げて／下げて」の向きと手ごたえの強さを頼りに、6回以内で正解へ。
- **ネタバレなしで共有** — 何回で当てたかを絵文字グリッドで表せます。正解の価格は共有文に含まれません。
- **登録不要・無料** — ブラウザだけで遊べます。遊んだ記録は端末内にのみ保存され、外部に送信されません。

## 価格について

出題の価格は、総務省「小売物価統計調査」等の公的統計を参考に当社が独自に概算した目安であり、統計の公表値そのものではありません。実際の価格は地域・時期・店舗によって変動します。商品は一般名詞で表しており、特定の商標・ブランドとは関係ありません。娯楽を目的としたゲームです。

出典・免責・プライバシーの詳細は [/privacy/](https://ga-project.github.io/ikura/privacy/) に掲載しています。

## 開発

```bash
./setup.sh     # 依存のインストール
pnpm dev       # http://localhost:3000
pnpm build     # out/ に静的書き出し
pnpm test      # ゲームロジックの回帰テスト
```

Next.js (App Router) の static export で、サーバーランタイムを必要としません。
